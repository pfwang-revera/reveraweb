EUDR，按风险等级应对

EUDR 不是一张通用清单。您需要做什么，取决于每项原料的产地：欧盟委员会将每个国家划分为低、标准或高风险，您的尽职调查义务随之递增。Keystone 从物料清单（BOM）中提取核心数据，请求补齐缺失信息并进行核查，提交至 TRACES，并保存尽职调查声明（DDS）编号以供复用，工作量按风险等级灵活调整。

EUDR 模块端到端工作流程

Keystone 基于您已有的产品数据运行完整的 EUDR 流程，您的团队只需审核和批准，无需手动整理。

  1. 1
    从物料清单中提取Keystone 自动识别与 EUDR 相关的组件（如木材、皮革或橡胶），并提取产品记录中已有的大宗商品类别、数量、供应商和产地数据。
  2. 2
    请求补齐缺失数据缺失的地理位置、合法性证明材料或生产日期，会通过 Keystone 通用的数据请求模块发送给相应供应商，必要时逐级向上游传递。
  3. 3
    由 AI 或专家验证（可选）AI 读取文件并核对数量与供应商；对于风险较高的产地，您还可以增加由我们团队进行的人工审核。
  4. 4
    提交至 TRACES经您批准后，系统根据产品记录生成尽职调查声明，并通过 API 提交至 TRACES。
  5. 5
    跟踪与复用Keystone 跟踪提交状态，并将每个 DDS 编号保存在产品记录中，以便在下游声明和后续发货中复用。

所有产品都需收集的信息

在适用任何风险等级之前，每个相关产品都需要相同的证明材料，并精确到其来源地块。

  • 大宗商品及其衍生产品（对家具和照明而言，即木材及木质部件）
  • 每个生产地块的地理位置，以坐标表示，较大地块需提供多边形边界
  • 生产国、数量以及生产日期或时间范围
  • 供应商信息，以及在该国合法生产的证明材料

工作量随风险等级递增

低风险国家

  • 简化尽职调查：收集信息并确认风险仅为可忽略水平
  • 无需完整的风险评估或风险缓解步骤，从这些国家采购的合规负担最轻

标准风险国家

  • 完整尽职调查：先收集信息，再进行有书面记录的风险评估，必要时采取风险缓解措施
  • 商品投放市场前，必须证明风险可忽略

高风险国家

  • 完整尽职调查外加强化审查，主管部门对此类经营者的检查比例也高得多
  • 每个地块和每份合法性文件都需要有据可查，上游数据的薄弱之处在这里最先暴露

AI 读懂供应商发来的真实文件

  • 识别多种语言和格式的文件、发票和认证证书，包括手写内容
  • 自动匹配上下游供应商并核对数量，确保整条链路数据吻合
  • 标记缺失和不一致之处供审核，在提交前发现问题文件
  • 减少对高成本人工专家审核的依赖，降低法律风险，同时保留您的最终审批权

Keystone 如何助力

  • 供应链数据请求在组件层级逐级向上游收集地理位置和合法性证明材料
  • 依据国家风险分级筛查产地，并标记高风险地块进行强化审核
  • 木材数据正确分层：树种和产地记录在批次上，产品详情记录在产品上
  • 经您批准后，系统根据产品记录生成尽职调查声明，并通过 API 提交至 TRACES
  • 评估责任仍由您承担；Keystone 负责与之相关的收集、核查和提交工作
来源：法规 (EU) 2023/1115（EUDR）第 9、10、13 和 29 条（国家风险分级与简化尽职调查）。
